# Mandalay Heritage App

A modern PHP heritage website inspired by heritage map and landmark listing experiences, tailored for Mandalay.

## Run locally

```bash
php -S 127.0.0.1:8000 -t public
```

Then open:

- http://127.0.0.1:8000/

## Project structure

- `public/index.php` — main landing page
- `public/assets/css/style.css` — styling
- `public/assets/js/main.js` — category filtering
